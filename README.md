# صانع إعلانات مزاج (Mazaj Ad Maker)

أداة مجانية تعمل داخل المتصفح. تعطيها صورة العطر الأصلي واسمه، وتطلع لك إعلان مزاج بنفس التصميم المعتمد.

## الرابط

https://mazaj911.github.io/mazaj-ad-maker/

الأداة مقفولة بكلمة سر. افتح الرابط، اكتب كلمة السر، والأداة تفتح في نفس الصفحة. بدون كلمة السر ما بتظهر.

## طريقة الاستخدام

1. افتح الرابط واكتب كلمة السر.
2. اختر صورة العطر الأصلي، واكتب الاسم بالعربي والإنجليزي.
3. انتظر القص التلقائي للخلفية. امسح البقايا بإصبعك لو وجدت.
4. اضغط تحميل الإعلان.

## التصميم

العبوة الأصلية 60% ظاهرة، وعبوة مزاج 50%، الاثنتان بارتفاع 510 على لوحة 1080، الخط الأبيض في المنتصف، الشعار في الأعلى، رقم الواتساب في الأسفل.

## الخصوصية

- المستودع عام، لكن محتوى الأداة مشفر بالكامل داخل index.html وما بينفتح بدون كلمة السر.
- الصور التي تختارها تُعالج في جهازك ولا تُرفع إلى أي سيرفر.
- القص بالذكاء الاصطناعي يستخدم مكتبة مفتوحة المصدر (@imgly/background-removal) تُحمّل من الإنترنت. بدون إنترنت تعمل الأداة بقص بسيط أقل دقة.
